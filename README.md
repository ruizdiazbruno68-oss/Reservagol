RESERVAGOL

Aplicacion para escritorio hecha con python, php, sqlite, tkinter.

Requiere Python 3.10 o superior con tkinter

Funciones:
Inicio de sesión: acceso mediante usuario y contraseña.

Registro de usuarios: creación de nuevas cuentas.

Gestión de canchas: registrar, modificar y eliminar canchas.

Gestión de horarios: configurar días y turnos disponibles.

Reservas: consultar disponibilidad, crear, modificar y cancelar reservas.

Gestión de clientes: administrar los datos de los usuarios.

Pagos: registrar señas, pagos parciales y completos.

Facturación: generar comprobantes y consultar movimientos.

Administración: gestionar usuarios, permisos y roles.

Panel principal: visualizar estadísticas generales del sistema.
